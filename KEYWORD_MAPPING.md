# Zedral Keyword Mapping & SEO Strategy

This document outlines the primary and secondary keywords targeted for each page of the Zedral platform, along with the structured data implemented to enhance search visibility.

## 🎯 Global Strategy
- **Primary Focus:** Operational Efficiency, Manufacturing Intelligence, Shopfloor Monitoring.
- **Geographic Focus:** India (Industrial hubs like Pune, Chennai, Gurgaon, Bangalore).
- **Target Audience:** Factory Managers, Production Heads, Operations Directors, CXOs in Manufacturing.

## 🛠️ Technical Implementation
- **Robots.txt:** Optimized for total crawlability.
- **Sitemap.xml:** Prioritized by section (Home > Capabilities > Blog > Legal).
- **SEO.tsx:** Dynamic meta tag injection for all pages.
- **Canonical Tags:** Implemented on every page to prevent duplicate content issues.
- **Language:** Explicitly set to `en` (English) globally.
